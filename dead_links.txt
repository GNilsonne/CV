HOW TO REPRODUCE THE CHECK
==========================

    cd CV
    python3 scripts/render_cv.py
    python3 - <<'PY'
    import re
    tex = open('output/cv.tex', encoding='utf-8').read()
    urls = re.findall(r'\\href\{([^}]*)\}', tex)
    seen = []
    for u in urls:
        for a, b in (('\\&','&'), ('\\_','_'), ('\\%','%'), ('\\#','#'), ('\\~','~')):
            u = u.replace(a, b)
        u = u.strip()
        if u.startswith(('http://', 'https://')) and u not in seen:
            seen.append(u)
    open('/tmp/allurls.txt', 'w').write('\n'.join(seen) + '\n')
    PY

Then check each URL with curl -L -m 25 and a desktop user agent. Before
calling anything dead:
  - re-verify DOIs returning 403/406/429 at https://api.crossref.org/works/<doi>
  - treat HTTP 200 with suspicion for repository links; check the provider API
    (for example https://api.osf.io/v2/preprints/<id>/), since moderation
    placeholders and SPA shells also return 200
  - retry 000 with -k to distinguish a TLS chain problem from a dead host, and
    check DNS with getent hosts to distinguish a dead domain from a firewall
Regenerate line numbers with grep -nF against cv_data.yaml, since several URLs
are stored LaTeX-escaped (\& and \%) and will not match the rendered form.
