HOW TO REPRODUCE
================

    cd CV
    python3 scripts/render_cv.py
    python3 - <<'PY'
    import re
    tex = open('output/cv.tex', encoding='utf-8').read()
    urls = re.findall(r'\\href\{([^}]*)\}', tex)
    seen = []
    for u in urls:
        for a, b in (('\\&','&'), ('\\_','_'), ('\\%','%'), ('\\#','#'), ('\\~','~')):
            u = u.replace(a, b)
        u = u.strip()
        if u.startswith(('http://', 'https://')) and u not in seen:
            seen.append(u)
    open('/tmp/allurls.txt', 'w').write('\n'.join(seen) + '\n')
    PY

Then check each URL with curl -L -m 25 and a desktop user agent, and re-verify
any DOI that returns 403, 406 or 429 against https://api.crossref.org/works/<doi>
before calling it dead. Regenerate line numbers with grep -nF against
cv_data.yaml, since several URLs are stored LaTeX-escaped (\& and \%) and will
not match the rendered form.
